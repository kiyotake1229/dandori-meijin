# App Store 用スクリーンショット

App Store Connect の「iPhone」のスクリーンショット欄に、フォルダごとにファイル名の番号の順でアップロードする。
透明なしの PNG。2026-10-20 にアプリの画面をそのまま撮った（記録の数字は見本）。

| フォルダ | 大きさ（横×縦 px） | 入れる欄 |
|---|---|---|
| `6.7/` | 1290 × 2796 | 6.9インチ（または 6.7インチ）ディスプレイ |
| `6.5/` | 1242 × 2688 | 6.5インチディスプレイ |
| `5.5/` | 1242 × 2208 | 5.5インチディスプレイ |

| 番号 | 画面 |
|---|---|
| 1-home | ホーム（今日の段取り No.24「カレーの日」・連続日数・練習） |
| 2-play | 段取りの途中（工程表に3枚置いたところと、作業カードの「いま置くと◯〜◯分」） |
| 3-result | 結果（★2・あなたの完成と最短・予想・ここがコツ） |
| 4-replay | 結果の下の「どこで差がついたか」（最短の段取りの再生と、並べ方の表） |
| 5-tutorial | はじめての段取り 第2話（案内の付箋つき） |
| 6-site-dark | 現場のお題 ★3（ダークテーマ） |

- 3-result・4-replay は練習の問題（★2・台所「餃子の日」）。日替わりの答えは見せていない（2-play は今日の段取りの途中まで）
- 撮り方: Google Chrome の画面なしモードで、ローカルに開いたアプリ（このフォルダの1つ上の `index.html`）を、画面の大きさ 430×932（6.7）・414×896（6.5）・414×736（5.5）、拡大率3倍で撮った。端末の時計は 2026年11月11日（水）に合わせ、記録は見本の値を入れた。音は消してから操作した。文字の行が画面の端や固定のバーで半分に切れないよう、数px だけ送ってから撮った
- 画面を大きく変えたときは撮り直す
