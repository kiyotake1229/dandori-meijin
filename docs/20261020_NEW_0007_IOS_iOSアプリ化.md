## 概要

Web アプリ本体（`index.html`）をそのまま同梱する iOS アプリのプロジェクト `ios-app/` を、嘘つき村の `ios-app/` と同じ形で Capacitor 7 で作った。Bundle ID は `work.ltv.dandori`、表示名は「段取り名人」、iPhone・縦向きのみ。`index.html` が使う5つのプラグイン（App・Haptics・LocalNotifications・Preferences・StatusBar）を入れ、`Info.plist`・プライバシーマニフェスト・アイコンと起動画面、App Store 用のスクリーンショット（3サイズ×6枚）、岩崎さん向けの `ios-app/岩崎さんへの引き渡し手順.md` をそろえた。手元の Mac には Xcode が無いので、ビルドの確認は GitHub Actions の macOS（macos-26・Xcode 26）で行う。
`index.html` と段取りエンジンは変えていないので、**問題は変わらない（VERSION 4 のまま）**。

### 2. `sync-web.sh`

- 親フォルダから `index.html` `manifest.json` `icon.svg` `icon-192.png` `icon-512.png` `apple-touch-icon.png` を `www/` にコピーする
- `sw.js`（Service Worker）は入れない（ネイティブでは使わない。`index.html` も `NATIVE` のときは登録しない）。`support.html` `ogp.png` `tools/` `docs/` も入れない
- `set -euo pipefail`。`index.html` が無ければエラーで止める。ほかのファイルが無いときは注意を出してとばす

### 3. Xcode プロジェクトの生成（`ios/`）

`npm install` → `npm run sync-web` → `npx cap add ios` → `npm run icons` の順で作った（Dropbox の外の作業用フォルダで行い、生成物を除いて `ios-app/` に写した）。

- `cap add ios` は Podfile（7つの Pod: Capacitor・CapacitorCordova と5プラグイン）を書き、**pod install まで成功**した（`Podfile.lock` あり）。最後の `xcodebuild` だけが「Xcode が無い」で失敗する。これは Capacitor の CLI が pod install のあとに行う掃除で、Xcode のある環境（GitHub Actions・岩崎さんの Mac）では通る（嘘つき村と同じ）
- 生成された `project.pbxproj` の Bundle ID は `work.ltv.dandori`、iOS 14.0 以上、Version 1.0 / Build 1。嘘つき村の `project.pbxproj` と比べ、違いは Bundle ID と、プライバシーマニフェストの参照の ID だけ（下の 5・6 を直したあと）

### 4. `Info.plist`

| キー | 値 | 理由 |
|---|---|---|
| `CFBundleDisplayName` | `段取り名人` | ホーム画面の名前（5字なのでアイコンの下で切れない。PWA の `short_name` と同じ） |
| `CFBundleDevelopmentRegion` / `CFBundleLocalizations` | `ja` / `[ja]` | 通知の許可など OS の部品を日本語で出す |
| `UISupportedInterfaceOrientations` | 縦（Portrait）だけ | 縦持ち・片手の設計。`~ipad` の行は消した（iPhone 専用のため） |
| `UIRequiredDeviceCapabilities` | `arm64` | 雛形は `armv7`。iOS 14 以上は arm64 だけなので実態に合わせた |
| `ITSAppUsesNonExemptEncryption` | NO | 輸出コンプライアンスの質問を省く（独自の暗号は使っていない） |
| `UIStatusBarStyle` | `UIStatusBarStyleDefault` | 起動直後の状態バーの文字色を端末のライト・ダークに合わせる（起動後は `index.html` が StatusBar で当てる） |
| `NSPhotoLibraryAddUsageDescription` | 入れない | 嘘つき村は共有シートで画像を保存するので要るが、このアプリには画像の保存が無い |
| `UIUserInterfaceStyle` | 入れない | アプリがライト・ダークの両方に対応しているので、端末の設定に任せる |

通知の説明文は要らない（ローカル通知の許可には `Info.plist` のキーが無い）。

### 5. iPhone 専用にした（`TARGETED_DEVICE_FAMILY = 1`）

嘘つき村と同じ理由（申請に iPad のスクリーンショットが要らない／iPad で縦向きだけにする `UIRequiresFullScreen` は iPadOS 26 で非推奨／画面は中央 480px の1列）。iPad では iPhone 用の画面のまま動く。iPad 対応にするときは `TARGETED_DEVICE_FAMILY` を `"1,2"` に戻し、`UISupportedInterfaceOrientations~ipad` を足し、iPad のスクリーンショットを用意する。

### 6. プライバシーマニフェスト（`PrivacyInfo.xcprivacy`）

| 中身 | 値 | 理由 |
|---|---|---|
| `NSPrivacyAccessedAPICategoryUserDefaults` | `CA92.1` | Preferences プラグイン（UserDefaults に保存） |
| `NSPrivacyTracking` / `NSPrivacyTrackingDomains` / `NSPrivacyCollectedDataTypes` | false / なし / なし | トラッキングなし・収集データなし |

- 嘘つき村にある `NSPrivacyAccessedAPICategoryFileTimestamp`（Filesystem プラグインの分）は、Filesystem を入れていないので外した
- Xcode が無いので、CocoaPods に入っている `xcodeproj`（Ruby）で `project.pbxproj` に足した（App グループへの参照と Resources への追加。あわせて `TARGETED_DEVICE_FAMILY` を 1 に）

### 7. アイコンと起動画面

- アイコン: `assets/icon.png`（#0006。藍の方眼紙に付箋の帯、透明なし）から `AppIcon-512@2x.png`（1024px、透明なし）を作った
- 起動画面: 雛形の起動画面（Capacitor の絵）は使わず、**角を丸めたアイコン（400px）をアプリの地の色の真ん中に置いた**画像を作った。ライト `#EDF2F4`、ダーク `#0A2240`（アプリのダークの地）。画面いっぱいに広げて表示されるので、iPhone の縦の画面でアイコンは約 110〜140pt。端末がダークのときはダーク版が出る

## 既知の注意・残作業

- **UIScene**: Capacitor 7 の雛形のままで UIScene に対応していない。Xcode 27 でビルドすると起動しないおそれがあるので、当面は Xcode 26 でビルドする（CI も Xcode 26）。2027年4月ごろまでに対応する（嘘つき村の #0016 の「決めてほしいこと 3」と同じ。岩崎さんの Mac が macOS 27 なら前倒し）
- **問い合わせ用のメールアドレス**: `support.html` の連絡先は GitHub の Issues だけ。清武さんがアドレスを決めたら、`support.html` のお問い合わせとプライバシーポリシー7章に足す（それまで申請しない）
- **起動直後の色**: WebView の背景はライトの地の色（`#EDF2F4`）1色。端末がダークのとき、起動画面（紺）からホームに切り替わる一瞬に明るい色が見える可能性がある。実機で確かめる
- **書体の通信**: 書体は Google Fonts から読む（オフラインでは端末の書体）。「データを収集しません」はこのままで出せる見込み。完全に通信をなくすなら、書体（Dela Gothic One・BIZ UDPGothic・IBM Plex Mono。どれも SIL OFL）を同梱する改修をする

- **公開リポジトリの中身**: リポジトリは public なので、`docs/`（工数・手元のパス）と `ios-app/岩崎さんへの引き渡し手順.md` は github.com のリポジトリの画面で誰でも読める（公開サイトでは `_config.yml` で隠している）。嘘つき村の #0016 の「決めてほしいこと 2」と同じ扱いで、清武さんの判断を待つ
