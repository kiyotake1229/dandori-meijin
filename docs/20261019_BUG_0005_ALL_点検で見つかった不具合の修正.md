## 概要

#0003・#0004 のあとの点検（遊び確認の QA 12件、コードレビュー 6件）の指摘を、一つずつ再現してから直した。大きかったのは、練習の［もう一度］の途中で離れると別の問題になる、予想のつまみの最初の位置（真ん中）がほぼ答え、「〜を置いたのが決め手」の約4割がその一手だけでは最短に届かない、前の版の記録に新しい版の結果が混ざる、の4つ。
**エンジンの VERSION を 3 → 4 に上げた。全員の日替わり・練習・はじめての段取りの問題が変わる**（2つある道具の決まり・★の難しさの条件・予想の範囲・部品表を変えたため）。まだ公開前なので、遊んだ人への影響は無い。
