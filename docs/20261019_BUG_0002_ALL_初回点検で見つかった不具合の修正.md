## 概要

初回の点検（遊び確認の QA とコードレビュー）で見つかった指摘を、一つずつ再現してから直した。いちばん大きかったのは、アプリ本体 `index.html` と検査 `tools/check-app.mjs` がまだ無く、画面の JavaScript が1行も無かったこと。下書き（CSS・アイコン・画面の骨組み）にエンジンと画面の JS を足して本体を仕上げ、検査を作り、指摘の残り（日付の丸め・解説の文・部品表の名前・CSS）を直した。
**エンジンの VERSION を 1 → 2 に上げた。全員の日替わり・練習の問題が変わる**（作業名と献立の部品を直したため）。

## 対象ファイル

- `index.html`（新規。エンジン・画面・CSS・SVG アイコン）
- `tools/check-engine.mjs`（検査を足した・直した）
- `tools/check-app.mjs`（新規）
- `README.md`・`docs/README.md`・`docs/20261019_DOC_0001_ALL_現状の仕様と構成.md`・`.claude/rules/documentation.md`（新規）

## 確認

- `node tools/check-engine.mjs index.html` → **PASS 78項目**（16〜19秒）。足した検査: 同じ名前の作業はいつも同じ資源／クレーンだけの作業に据える・立てる等を使わない／1つの献立に卵料理を2品入れない／「流れ」の文で前提の無い所を「→」だけで書かない／1枚動かせば届くならそのカードを勧める。直す前のエンジン（VERSION 1）では、この5つがすべて FAIL することを確かめた
- 回帰ハッシュ（VERSION 2）: daily365 `bb115a31049e2311663bf71de26f20e7`、practice120 `d79c68e10db331d8a4507a797049a782`、fixed4 `74334e8db2d5e03cb3bc51165e8ec3d5`
- `node tools/check-app.mjs index.html` → **PASS 60項目**。わざと壊した写し（丸めを外す・color-mix と 9px に戻す・epoch の確認を外す）では、それぞれ該当の項目が FAIL することを確かめた
- ブラウザ（アプリ内の Browser・スマホ幅 375px、ミュートのスクリプトを流してから操作）で通しの確認: 初回のホーム → はじめての段取り3話（第2話は一度わざと外して［もう一度］）→ 今日の段取り No.1（予想 14分 → 上から順で17分 → ［もう一度］→ 途中でホームに戻り「やり直しの続きから」→ 13分で最短。「2回目で最短」）→ 最短の再生・結果のコピー（この環境はクリップボードが使えず、選択済みの文の欄が出る）→ 練習 ★3・現場（1つ戻す・最初から・次の問題・戻る）→ 記録帳 → 設定でダーク。コンソールのエラー 0、`__muteReport` の intercepted 1。320px 幅でも横スクロールなし。端末の時計を 10-18 23:55 にした場合も、No.1（洋食の朝ごはん）と「日付を確かめて」が出ることを確かめた。確認で作った localStorage は消した
